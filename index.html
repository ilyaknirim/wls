💧 ДАТЧИК УРОВНЯ ВОДЫ · 7 ИНЖЕНЕРНЫХ ЭКСПЕРИМЕНТОВ

Принцип работы: датчик измеряет электрическое сопротивление между дорожками. Вода проводит ток — сопротивление падает, напряжение на аналоговом пине растёт.

🔌 БАЗОВОЕ ПОДКЛЮЧЕНИЕ (все эксперименты)
VCC → 5V (питание)
GND → GND (земля)
SIG → A0 (аналоговый сигнал)

📌 ЭКСПЕРИМЕНТ 1 · ЧТЕНИЕ СЫРЫХ ДАННЫХ

analogRead() · Монитор порта · Диапазон 0–1023

Схема та же, что и в базовом подключении.
// ЭКСПЕРИМЕНТ 1: Мониторинг сырых значений // Задача: наблюдать, как меняется сигнал в воздухе, при касании, при погружении #define SENSOR_PIN A0 void setup() { Serial.begin(9600); Serial.println("=== ДАТЧИК ВОДЫ: РЕЖИМ ИЗМЕРЕНИЙ ==="); Serial.println("Воздух | Касание | Погружение"); Serial.println("0-1023"); } void loop() { int rawValue = analogRead(SENSOR_PIN); Serial.print("Сырой сигнал: "); Serial.print(rawValue); // Комментарий по состоянию if (rawValue < 50) Serial.print(" — СУХО (воздух)"); else if (rawValue < 300) Serial.print(" — ВЛАЖНО (конденсат/касание)"); else if (rawValue < 600) Serial.print(" — МОКРО (частичное погружение)"); else Serial.print(" — ПОЛНОЕ ПОГРУЖЕНИЕ"); Serial.println(); delay(300); }
🔬 ФАКТ О КОДЕ: analogRead() возвращает значение от 0 до 1023. Это потому, что АЦП (аналого-цифровой преобразователь) Arduino — 10-битный. 2¹⁰ = 1024 дискретных уровня. Напряжение 0В = 0, 5В = 1023. Датчик работает как переменный резистор: сухой → высокое сопротивление → низкое напряжение (ближе к 0). Мокрый → низкое сопротивление → высокое напряжение (ближе к 5В).
📊 ПРИМЕНЕНИЕ: В реальных системах такие сырые значения никогда не используют напрямую. Всегда применяют калибровку и привязку к физическим величинам (мм, %, мл).

📌 ЭКСПЕРИМЕНТ 2 · ПОРОГОВОЕ СРАБАТЫВАНИЕ

if (value > threshold) · digitalWrite · Простейший детектор

// ЭКСПЕРИМЕНТ 2: Световая индикация превышения порога // Встроенный светодиод на пине 13 загорается при обнаружении воды #define SENSOR A0 #define LED 13 int threshold = 300; // Эмпирическое значение (зависит от датчика) void setup() { pinMode(LED, OUTPUT); Serial.begin(9600); Serial.println("=== ПОРОГОВЫЙ ДЕТЕКТОР ==="); Serial.print("Порог срабатывания: "); Serial.println(threshold); } void loop() { int value = analogRead(SENSOR); if (value > threshold) { digitalWrite(LED, HIGH); // Вода есть } else { digitalWrite(LED, LOW); // Воды нет } // Для отладки выводим каждые 500 мс static unsigned long lastPrint = 0; if (millis() - lastPrint > 500) { lastPrint = millis(); Serial.print("Сигнал: "); Serial.print(value); Serial.print(" — "); Serial.println(value > threshold ? "ВОДА" : "СУХО"); } }
⚡ ФАКТ О КОДЕ: Использование static unsigned long lastPrint — это приём для неблокирующих задержек. В отличие от delay(), он позволяет опрашивать датчик максимально часто, но выводить в порт только раз в полсекунды. Так мы не пропускаем быстрые изменения.
🧠 ПРОБЛЕМА ПОРОГА: Значение 300 взято "с потолка". У разных экземпляров датчиков, при разном напряжении питания, в разной воде показания отличаются. Инженерное решение — калибровка (эксперимент 5).

📌 ЭКСПЕРИМЕНТ 3 · ЗВУКОВАЯ СИГНАЛИЗАЦИЯ

Пьезозуммер · Частота · Предупреждение о превышении

// ЭКСПЕРИМЕНТ 3: Звуковое оповещение // Активный зуммер (генерирует тон сам при подаче HIGH) #define SENSOR A0 #define BUZZER 8 #define THRESHOLD 350 void setup() { pinMode(BUZZER, OUTPUT); Serial.begin(9600); Serial.println("=== ЗВУКОВОЙ СИГНАЛИЗАТОР ==="); } void loop() { int value = analogRead(SENSOR); if (value > THRESHOLD) { digitalWrite(BUZZER, HIGH); Serial.println("⚠️ ПРЕВЫШЕНИЕ УРОВНЯ"); } else { digitalWrite(BUZZER, LOW); } delay(50); // Небольшая задержка для стабильности }
🔊 ФАКТ О КОМПОНЕНТАХ: Активный зуммер имеет встроенный генератор частоты — достаточно подать напряжение, и он пищит. Пассивный зуммер требует генерации сигнала через tone(). В проектах с водой активный зуммер предпочтительнее — меньше проводов и кода.
📏 МАСШТАБИРОВАНИЕ: В промышленных системах звуковая сигнализация всегда дублируется световой. Человек хуже слышит высокие частоты с возрастом — поэтому используют прерывистый сигнал (мигание + писк).

📌 ЭКСПЕРИМЕНТ 4 · АНАЛОГОВАЯ ИНДИКАЦИЯ

map() · constrain() · Яркость = Уровень воды

// ЭКСПЕРИМЕНТ 4: Аналоговая индикация // Яркость светодиода пропорциональна уровню воды #define SENSOR A0 #define LED_PWM 9 // Обязательно PWM (~) пин! int dryValue = 60; // Значение в сухом воздухе (измерить заранее) int wetValue = 700; // Значение в полностью погруженном состоянии void setup() { pinMode(LED_PWM, OUTPUT); Serial.begin(9600); Serial.println("=== АНАЛОГОВАЯ ИНДИКАЦИЯ ==="); Serial.print("Диапазон калибровки: "); Serial.print(dryValue); Serial.print(" — "); Serial.println(wetValue); } void loop() { int raw = analogRead(SENSOR); // Ограничиваем значения в пределах калибровки raw = constrain(raw, dryValue, wetValue); // Преобразуем диапазон датчика (dry..wet) в диапазон ШИМ (0..255) int brightness = map(raw, dryValue, wetValue, 0, 255); analogWrite(LED_PWM, brightness); // Отладка static unsigned long lastPrint = 0; if (millis() - lastPrint > 800) { lastPrint = millis(); Serial.print("Сырой: "); Serial.print(raw); Serial.print(" | Яркость: "); Serial.println(brightness); } }
🔄 ФАКТ О MAP(): Функция map(value, fromLow, fromHigh, toLow, toHigh) — пропорциональное масштабирование. Она НЕ ограничивает значения. Если raw = 800, а wetValue = 700, то map() вернёт значение больше 255. Именно поэтому перед map() всегда ставят constrain().
⚡ PWM (ШИМ): analogWrite() не выдаёт аналоговое напряжение, а генерирует прямоугольные импульсы. 0 = 0В, 255 = 5В постоянно, 127 = 2.5В (50% времени 5В, 50% 0В). Глаз видит это как яркость.

📌 ЭКСПЕРИМЕНТ 5 · АВТОМАТИЧЕСКАЯ КАЛИБРОВКА

Кнопка · INPUT_PULLUP · Усреднение · Запоминание

// ЭКСПЕРИМЕНТ 5: Автоматическая калибровка // Кнопка: нажать в воздухе — запомнить сухо // Кнопка: нажать в воде — запомнить мокро #define SENSOR A0 #define BUTTON 2 #define LED 13 int dryValue = 0; int wetValue = 0; bool calibrated = false; void setup() { pinMode(BUTTON, INPUT_PULLUP); // Внутренний подтягивающий резистор pinMode(LED, OUTPUT); Serial.begin(9600); Serial.println("=== РЕЖИМ КАЛИБРОВКИ ==="); Serial.println("1. Держите датчик СУХИМ, нажмите кнопку"); } void loop() { if (digitalRead(BUTTON) == LOW) { delay(200); // Антидребезг if (dryValue == 0) { // Калибровка сухого состояния dryValue = readAverage(20); // Усредняем 20 измерений Serial.print("✅ СУХО зафиксировано: "); Serial.println(dryValue); Serial.println("2. Опустите датчик в ВОДУ, нажмите кнопку"); blinkLED(2); } else if (wetValue == 0) { // Калибровка мокрого состояния wetValue = readAverage(20); Serial.print("✅ МОКРО зафиксировано: "); Serial.println(wetValue); calibrated = true; Serial.println("=== КАЛИБРОВКА ЗАВЕРШЕНА ==="); blinkLED(3); } while(digitalRead(BUTTON) == LOW); // Ждём отпускания delay(200); } // Режим измерения if (calibrated) { int raw = analogRead(SENSOR); raw = constrain(raw, dryValue, wetValue); int percent = map(raw, dryValue, wetValue, 0, 100); Serial.print("📊 ВЛАЖНОСТЬ: "); Serial.print(percent); Serial.println("%"); // Индикация яркостью (пульсация) int brightness = map(percent, 0, 100, 0, 255); analogWrite(LED, brightness); // 13 пин не PWM! Заменить на 9,10,11 в реальной схеме // Для пина 13 используем мигание с разной частотой digitalWrite(LED, HIGH); delay(percent * 2); digitalWrite(LED, LOW); delay(percent * 2); } delay(100); } // Функция усреднения для подавления шумов int readAverage(int samples) { long sum = 0; for (int i = 0; i < samples; i++) { sum += analogRead(SENSOR); delay(10); } return sum / samples; } // Функция мигания для обратной связи void blinkLED(int count) { for (int i = 0; i < count; i++) { digitalWrite(LED, HIGH); delay(150); digitalWrite(LED, LOW); delay(150); } }
🎛️ ФАКТ О INPUT_PULLUP: INPUT_PULLUP активирует внутренний резистор 20–50 кОм, подтягивающий пин к +5В. Кнопка замыкает пин на GND. Когда кнопка не нажата — читаем HIGH. Нажата — LOW. Это экономит внешние компоненты.
📈 ФАКТ ОБ УСРЕДНЕНИИ: Датчик воды — "шумный" компонент. Малейшие колебания воды, пузырьки воздуха меняют сопротивление. Усреднение 20–50 измерений даёт стабильные значения. В реальной гидропонике используют скользящее среднее (moving average) или медианную фильтрацию.

📌 ЭКСПЕРИМЕНТ 6 · МНОГОУРОВНЕВАЯ СИСТЕМА

4 дискретных уровня · Светодиодная шкала

// ЭКСПЕРИМЕНТ 6: Многоуровневая индикация // 4 состояния: СУХО, ВЛАЖНО, МОКРО, КРИТИЧЕСКИ #define SENSOR A0 #define GREEN 9 #define YELLOW 10 #define RED 11 // Пороги (после калибровки) int levels[4] = {0, 200, 400, 600}; // СУХО, ВЛАЖНО, МОКРО, КРИТИЧЕСКИ void setup() { pinMode(GREEN, OUTPUT); pinMode(YELLOW, OUTPUT); pinMode(RED, OUTPUT); Serial.begin(9600); Serial.println("=== 4-УРОВНЕВЫЙ ИНДИКАТОР ==="); } void loop() { int value = analogRead(SENSOR); int level = 0; // Определяем уровень if (value < levels[1]) level = 0; // СУХО else if (value < levels[2]) level = 1; // ВЛАЖНО else if (value < levels[3]) level = 2; // МОКРО else level = 3; // КРИТИЧЕСКИ // Управление светодиодами switch(level) { case 0: // СУХО — все выключены digitalWrite(GREEN, LOW); digitalWrite(YELLOW, LOW); digitalWrite(RED, LOW); break; case 1: // ВЛАЖНО — зелёный digitalWrite(GREEN, HIGH); digitalWrite(YELLOW, LOW); digitalWrite(RED, LOW); break; case 2: // МОКРО — жёлтый digitalWrite(GREEN, LOW); digitalWrite(YELLOW, HIGH); digitalWrite(RED, LOW); break; case 3: // КРИТИЧЕСКИ — красный digitalWrite(GREEN, LOW); digitalWrite(YELLOW, LOW); digitalWrite(RED, HIGH); break; } // Вывод в монитор static unsigned long lastPrint = 0; if (millis() - lastPrint > 500) { lastPrint = millis(); Serial.print("Сигнал: "); Serial.print(value); Serial.print(" | Уровень: "); Serial.print(level); Serial.print(" ("); switch(level) { case 0: Serial.print("СУХО"); break; case 1: Serial.print("ВЛАЖНО"); break; case 2: Serial.print("МОКРО"); break; case 3: Serial.print("КРИТИЧЕСКИ"); break; } Serial.println(")"); } }
🎯 ФАКТ О ДИСКРЕТИЗАЦИИ: Превращение непрерывного сигнала (0–1023) в конечное число состояний называется дискретизацией по уровню (квантованием). В АЦП это неизбежно. В датчиках дождя для автомобилей обычно используют 2-3 порога: "сухо", "влажно", "сильный дождь".
💡 ПРИМЕНЕНИЕ: Именно так работают индикаторы уровня жидкости в стиральных машинах, посудомойках, системах автополива. Там нет экранов — только светодиоды.

📌 ЭКСПЕРИМЕНТ 7 · ИЗМЕРЕНИЕ ПРОВОДИМОСТИ ВОДЫ

Сравнение водопроводной и дистиллированной воды

// ЭКСПЕРИМЕНТ 7: Тест проводимости воды // Чистая вода НЕ проводит ток! Ток проводят растворённые соли. #define SENSOR A0 void setup() { Serial.begin(9600); Serial.println("=== ТЕСТ ПРОВОДИМОСТИ ВОДЫ ==="); Serial.println("Подготовьте образцы:"); Serial.println("1. Водопроводная вода"); Serial.println("2. Кипячёная вода"); Serial.println("3. Дистиллированная вода"); Serial.println("4. Солевой раствор (ложка соли на стакан)"); Serial.println("================================="); delay(3000); } void loop() { int value = analogRead(SENSOR); Serial.print("Значение АЦП: "); Serial.print(value); Serial.print(" | "); if (value < 100) Serial.print("💧 ДИСТИЛЛИРОВАННАЯ (изолятор)"); else if (value < 300) Serial.print("🚰 КИПЯЧЁНАЯ (меньше солей)"); else if (value < 600) Serial.print("💦 ВОДОПРОВОДНАЯ (средняя проводимость)"); else Serial.print("🧂 СОЛЕВОЙ РАСТВОР (высокая проводимость)"); Serial.println(); delay(500); }
🧪 ФАКТ О ПРОВОДИМОСТИ: Химически чистая (дистиллированная) вода — диэлектрик. Её удельное сопротивление ~18 МОм·см. Водопроводная вода проводит ток из-за растворённых солей кальция, магния, натрия. Именно поэтому датчик воды — это фактически датчик минерализации.
⚠️ ФАКТ О ДОЛГОВЕЧНОСТИ: Датчики воды с открытыми медными дорожками подвержены электролизу. Постоянный ток вызывает коррозию. В профессиональных системах используют переменный ток или кратковременные импульсы для измерения, чтобы продлить срок службы.
🔋 ПРИМЕНЕНИЕ: Аналогичный принцип используется в TDS-метрах (Total Dissolved Solids) — измерителях общего количества растворённых твёрдых веществ. TDS-метр показывает, сколько миллиграмм солей на литр воды.

📌 ЗАДАЧИ ДЛЯ САМОСТОЯТЕЛЬНОЙ РАБОТЫ

🔹 Уровень 1 (базовый)
  • Изменить порог срабатывания и подобрать для своего стакана
  • Добавить второй светодиод, который горит при сильном намокании
  • Сделать прерывистый звуковой сигнал (0.5 сек писк, 0.5 сек пауза)
🔸 Уровень 2 (средний)
  • Реализовать скользящее среднее для фильтрации шумов (буфер на 10 значений)
  • Добавить второй датчик на пин A1 и сравнивать показания двух стаканов
  • Выводить данные в виде ASCII-графика в монитор порта (строка из символов █)
🔹 Уровень 3 (продвинутый)
  • Использовать EEPROM для сохранения калибровочных значений после выключения
  • Реализовать гистерезис (два порога: включения и выключения) для стабильной работы
  • Подключить ЖК-дисплей I2C и выводить уровень в процентах и мм
